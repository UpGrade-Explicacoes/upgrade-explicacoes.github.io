# UpGrade

Site das explicações UpGrade. Página única em HTML, sem custos de alojamento.

## Publicar no GitHub Pages
1. Cria um repositório público chamado upgrade
2. Carrega index.html e favicon.svg
3. Settings, Pages, Source "Deploy from a branch", branch main, pasta root
4. O site fica em https://O_TEU_UTILIZADOR.github.io/upgrade/
